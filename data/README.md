# Source data

Source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

Place the eight required CSV files in `data/raw/`. The optional `olist_geolocation_dataset.csv` may be present for inventory purposes but is not required or used in the primary analysis. Raw files are intentionally excluded from Git because of size, licensing, and reproducibility concerns. The pipeline validates source headers before loading.
