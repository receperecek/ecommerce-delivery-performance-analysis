# Metric dictionary

| Metric | Definition |
|---|---|
| Eligible delivered order | Delivered order with both customer-delivered and estimated-delivery dates present |
| Late delivery rate | Late eligible orders / all eligible delivered orders |
| Delay days | Calendar-date difference between delivered and estimated dates, for late orders |
| Gross order value | Sum of item price and freight value |
| At-risk order value | Gross order value for late eligible delivered orders |
| Review score gap | Mean score for early/on-time orders minus mean score for late orders |
| Dispatch SLA breach | Carrier handoff after the earliest shipping limit for an order-seller pair |
